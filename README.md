# Kanban Task Board

A React + Vite Kanban board project for internship Week 5.

## Features

- 3 columns: To Do, In Progress, Done
- Add tasks
- Delete tasks
- Move tasks between columns
- Drag and drop tasks between columns (dnd-kit)
- Edit task title inline
- Priority selection (High, Medium, Low)
- Priority-based card border colors
- localStorage persistence
- Search task by title

## Tech Stack

- React (JSX)
- Vite
- dnd-kit
- CSS

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
